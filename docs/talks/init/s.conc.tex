\section{Conclusion}
%-------------------------------------------------------------------------------
\begin{frame}{Limitations \& Future work}
  \paragraph{Limitations}
  \begin{itemize}
    \item Did not consider temporary breaks in sex work
    \item Have not yet applied to individual-level data
    \item Assumed equilibrium
  \end{itemize}
  \bigskip
  \paragraph{Future Work}
  \begin{itemize}
    \item Directly model \emph{exit rates} from sex work instead of parametric duration distributions
       \\ \rarr integrate covariates, frailties, more intuitive priors
    \item Jointly model duration, age, \& calendar time
  \end{itemize}
\end{frame}
%-------------------------------------------------------------------------------
\begin{frame}{Summary}
  \begin{itemize}
    \item Mean sex work duration from cross-sectional studies: 3 competing biases
    \begin{enumerate}
      \item \textbf{Length-biased sampling:} increases the mean
      \item \textbf{Universal random censoring:} halves the mean
      \item \textbf{Undersampling early sex work:} increases the mean, slightly
    \end{enumerate}
    \item Prior review ignored 1 \& 3, and thus overestimated mean sex work durations
    \item True durations in sex work likely short \& heavy-tailed
    \item Methods here can help infer any duration distribution from cross-sectional data
  \end{itemize}
\end{frame}
