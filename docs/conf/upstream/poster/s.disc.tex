\section{Discussion}
\paragraph{Implications}
\begin{itemize}
  \item Shorter sex work durations suggest higher HIV/STI incidence within sex work
   \par than previously thought, to accumulate and match prevalence data \cite{Knight2020}
  \item Critical to reach early sex work (e.g. first year) with HIV/STI services
   \par as many women may experience \emph{only} this vulnerable period \cite{Cheuk2020}
  \item Heavy-tailed survival function suggests within- and/or between-person
   \par heterogeneity in sex work exit rates \cite{Balan2020}
  \item Relationships derived apply to any cross-sectionally-estimated durations
\end{itemize}
\paragraph{Limitations \& Future Work}
\begin{itemize}
  \item Did not model any reporting biases, or gaps in sex work; assumed equilibrium
  \item Could directly model exit rates, not parametric duration distributions $f(x)$
  \item Could then incorporate covariates (e.g. age, calendar time)
\end{itemize}
